# Проект веб-приложения онлайн курсов
## Описание:
**Данное приложение предполагает создание веб-приложения онлайн курсов.**
## Цель проекта:
Реализовать приложение, которое позволяет пользователям размещать свои полезные материалы или курсы.
## Установка:
1. Клонируйте репозиторий:
```python
https://github.com/PetrMaev/online_courses_CI_CD.git
```
```python
git@github.com:PetrMaev/online_courses_CI_CD.git
```
2. Установите зависимости:
```python
poetry install
```
## Наполнение данными базы данных:
Для наполнения данными базы данных используйте фикстуры и кастомные команды.
1. Кастомная команда для заполнения базы данных курсами и уроками:
```python
python manage.py add_data
```
2. Кастомная команда для создания суперпользователя:
```python
python manage.py csu
```
3. Кастомная команда для создания группы модераторов и добавления пользователя-модератора:
```python
python manage.py create_moderator
```
4. Кастомная команда для заполнения базы данных платежами:
```python
python manage.py add_payments
```
## Использование:
Для запуска программы введите в терминале следующую команду:
```python
python manage.py runserver
```
## Запуск приложения с использованием docker-compose
1. Для запуска проекта с docker-compose выполните следующую команду:
```python
docker-compose up --build
```
2. Для остановки работающих контейнеров используйте следующую команду:
```python
docker-compose down
```
4. Для просмотра логов и мониторинга работы контейнеров используйте команду:
```python
docker-compose logs
```
3. Для вывода списка всех контейнеров используйте команду:
```python
docker-compose ps
```
## В проекте реализованы:
1. CRUD операции с курсами на базе ViewSet
2. CRUD операции с уроками, пользователями и платежами на базе Generics
3. Регистрация пользователей
4. Авторизация
5. Валидация ссылок на видеоматериалы уроков 
6. Пагинация списка курсов и уроков
7. Возможности подписки на курс
8. Рассылка электронных писем подписчикам курса об обновлениях
## Дополнительная информация:
### I. Настройки удаленного сервера.
1. Подключитесь к виртуальной машине с помощью команды:
```python
ssh <имя_пользователя>@<IP_адрес сервера>
```
2. Установка Git

Откройте терминал на сервере и выполните команду:
```python
sudo apt update
sudo apt install git
```
Убедитесь, что Git установлен корректно, выполнив команду:
```python
git --version
```
Если всё установлено правильно, команда выведет номер версии Git.

3. Клонирование репозитория с GitHub

Перейдите в директорию, где вы хотите разместить код вашего приложения. Например:
```python
cd /var/www
```
Где /var/www — это директория, куда вы хотите склонировать проект.

Затем выполните команду для клонирования репозитория:
```python
git clone https://github.com/username/repository.git
```
Замените username/repository на путь к вашему репозиторию.

После выполнения этой команды весь код из репозитория будет скопирован на ваш сервер в указанную директорию.
4. Запуск контейнеров

Перейдите в директорию, где находится ваш файл docker-compose.yml. Например:
```python
cd /var/www/repository
```
Замените /var/www/repository на директорию, куда проект был склонирован.

Выполните команду для запуска контейнеров:
```python
docker-compose up -d
```
Эта команда соберет Docker-образы, если они еще не собраны, запустит контейнеры и свяжет их между собой 
в соответствии с конфигурацией, описанной в docker-compose.yml.
### II. Реализация деплоя с помощью GitHub Actions
В проекте реализована автоматическая проверка кода и деплой кода на удаленный сервер при пуше кода в GitHub репозиторий.

Включает в себя следующие шаги:
1. Проверка кода линтером flake8
2. Запуск тестов
3. Создание докер образа на DockerHub
4. Деплой кода на удаленный сервер
